An API that reads and writes classical harmony

Analyze MusicXML/MIDI to Roman numerals, propose idiomatic progressions, and realize four-part SATB scores — deterministic FastAPI endpoints with live responses below.

Checking server… Local demo · no auth OpenAPI /docs
